# referencias-assets

Carpeta de trabajo para todo lo que vaya generando ChatGPT (y las
herramientas de imagen a 3D) a partir de `Prompts_ChatGPT_CapituloII.pdf`
(en la raíz del proyecto).

Guarda aquí cada imagen, variación, modelo o guion que te entregue, aunque
sea un borrador o una versión descartada. No hace falta que el nombre de
archivo sea el definitivo ni que el formato sea el final: esto es solo un
almacén de trabajo.

Las subcarpetas siguen el mismo orden que el PDF:

- `01_retratos/` — retratos de diálogo de Neri, Luma y Maren (sección 4)
- `02_interludio/` — las 4 viñetas del interludio del Capítulo II (sección 5)
- `03_epilogo/` — las 4 viñetas del epílogo (sección 6)
- `04_postales/` — postales de las cuatro islas (sección 7)
- `05_iconos/` — los 13 iconos de la Constelación de Neri (sección 8)
- `06_hojas_personaje/` — hojas de referencia de personajes y enemigos (sección 10)
- `07_arte_clave/` — arte clave de promoción (sección 11)
- `08_video/` — planos del tráiler y el teaser (sección 12)
- `09_modelo_neri/` — las 3 imágenes de referencia y el `.glb` del nuevo modelo de Neri (sección 9)
- `10_guiones/` — textos y guiones (sección 13)

Cuando una imagen o un texto te convenza, dímelo o cópialo directamente a su
ruta final dentro de `godot/assets/...` (la ruta exacta está en cada sección
del PDF), y abre el proyecto una vez con `Abrir_editor.cmd` para que Godot
la importe. El modelo 3D de Neri lo integro yo directamente en Blender.
